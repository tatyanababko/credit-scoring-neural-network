  • {% if comparison.summary.nn_advantage_over_best_alt > 0 %} Преимущество нейронной сети над лучшим из альтернативных методов ({{ comparison.summary.best_alternative }}) составляет +{{ "%.4f"|format(comparison.summary.nn_advantage_over_best_alt) }} по ROC-AUC, что подтверждает целесообразность использования нейросетевого подхода в задаче кредитного скоринга. {% else %} На данном датасете нейронная сеть демонстрирует результаты, сопоставимые с лучшим из альтернативных методов ({{ comparison.summary.best_alternative }}). Это типичная ситуация для табличных данных, где градиентный бустинг часто оказывается сильным конкурентом нейросетям. {% endif %}
  • Использование нейронной сети с архитектурой {{ metadata.n_features }}-{{ metadata.hyperparameters.units_1 }}-{{ metadata.hyperparameters.units_2 }}-{{ metadata.hyperparameters.units_3 }}-1 обусловлено возможностью применения BatchNormalization, Dropout и адаптивных оптимизаторов, что обеспечивает устойчивость к переобучению и хорошее обобщение на новые данные.
  • Для регуляторной отчётности и обеспечения интерпретируемости решений модель может быть дополнена методом SHAP (SHapley Additive exPlanations), позволяющим объяснить вклад каждого признака в конечное решение.
