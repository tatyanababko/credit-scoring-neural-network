# Кредитный скоринг — нейросетевая система со сравнительным анализом

Веб-приложение для прогнозирования вероятности одобрения кредита на основе обученной нейронной сети (TensorFlow / Keras). Включает сравнительный анализ с альтернативными моделями машинного обучения.

## Структура проекта

```
credit_scoring_app/
├── train_model.py          # Обучение + сравнительный анализ
├── app.py                  # Flask backend
├── requirements.txt
├── README.md
├── Скоринг.csv             # положить рядом
│
├── models/                 # создаётся train_model.py
│   ├── credit_scoring_model.keras   # обученная нейросеть
│   ├── scaler.joblib                # нормализатор
│   ├── features.json
│   ├── model_metadata.json
│   ├── training_history.json
│   └── comparison_results.json      # ← результаты сравнения
│
├── templates/
│   ├── index.html          # форма скоринга
│   ├── dashboard.html      # дашборд с метриками
│   ├── comparison.html     # ← страница сравнения моделей
│   └── no_comparison.html

    └── style.css
```

## Установка и запуск

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Поместить Скоринг.csv в корень проекта

# 3. Обучение модели + сравнительный анализ
python train_model.py

# 4. Анализ признаков (распределения, статистика)
python analyze_features.py

# 5. Запуск веб-приложения
python app.py

# 6. Открыть в браузере: http://localhost:5000
```

## Что делает скрипт обучения

`train_model.py` выполняет 7 этапов:

1. **Загрузка данных** — чтение `Скоринг.csv`, фильтрация
2. **Инженерия признаков** — формирование 32 признаков
3. **Обучение нейронной сети** — TensorFlow/Keras с Dropout, BatchNorm, Adam
4. **Подбор порога классификации** — оптимизация F1-score на валидации
5. **Сравнительный анализ** — обучение 4 альтернативных моделей:
   - Логистическая регрессия
   - Дерево решений (CART)
   - Случайный лес (200 деревьев)
   - Градиентный бустинг (200 итераций)
6. **Ранжирование моделей** по ROC-AUC
7. **Сохранение всех артефактов**

## Веб-интерфейс

### Главная `/`
Форма подачи кредитной заявки с расчётом скоринга в реальном времени.

### Дашборд `/dashboard`
- Метрики качества нейронной сети
- Краткое сравнение с альтернативными моделями (топ-5)
- Параметры архитектуры и обучения
- Матрица ошибок
- Статистика обработанных заявок и история

### Сравнительный анализ `/comparison`
- Сводка результатов (победитель, преимущество нейросети)
- Полная таблица метрик (ROC-AUC, Gini, KS, F1, Precision, Recall, Accuracy, время)
- Визуальное сравнение по ROC-AUC (горизонтальные диаграммы)
- Описание каждой модели
- Выводы и обоснование выбора нейронной сети

### Анализ признаков `/features`
- Сводная статистика по всем 32 признакам
- Сводный график: масштабы признаков до и после нормализации (boxplot)
- Корреляционная матрица (heatmap)
- Таблица всех признаков с min/max/mean/std/уникальных значений
- Детальная страница для каждого признака:
  - Гистограмма распределения **до** нормализации (с разделением по классам)
  - Гистограмма распределения **после** StandardScaler
  - Полная статистика (min, max, mean, std, медиана, квартили)
  - Параметры scaler (μ, σ) и формула преобразования

## Шкала решений (трёхуровневая)

| Вероятность | Решение |
|---|---|
| 0–20% | Автоматический отказ |
| 20% – порог | На рассмотрение эксперту |
| Порог – 75% | Одобрено |
| 75–100% | Автоматическое одобрение |

Граница «порог» подбирается автоматически по F1-score на валидации.

## Технологии

- **TensorFlow 2.x / Keras** — нейронная сеть

- **joblib** — сериализация
- **HTML/CSS/JavaScript** — фронтенд
